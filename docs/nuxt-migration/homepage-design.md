# Shun 首页设计

## 先设计

首页服务想了解作者、阅读技术笔记、查看实际项目的读者。首要任务是从作者观点走向可阅读的真实内容。

色彩：冷白 `#f7f9fc` 为页面底色，石墨 `#1f2937` 为主文字，蓝 `#345bcb` 为链接与操作，淡蓝 `#e8efff` 为工作台背景，珊瑚 `#d65b49` 仅用于小面积标记。白色用于内容面板；辅助文字用 `#596579`。

字体：display 使用本地 Songti SC / STSong / SimSun，限于作者主张；body 使用系统中文 sans；utility 使用 Consolas / 系统 monospace。没有远程字体请求。

布局：比较过全宽声明加文章网格、左右作者与工作台两种方向。选择后者，使真实文章出现在首屏，避免作者介绍占满阅读入口。

```text
桌面
┌ 主代理的站点导航 ─────────────────────────┐
│ 作者 / 技术方向        │ 工作台：真实写作索引 │
│ 与概率同行，          │ Agent / RAG 阅读入口│
│ 为结果负责。          │ 项目阅读入口         │
├ 精选文章 ────────────────────────────────┤
│ 真实标题、描述、标签；无精选则使用近期文章  │
├ 企业知识问答项目      │ 近期更新             │
├ AI 应用 / 软件工程 / 个人实践方向说明 ────┤
└ 主代理的页脚 ────────────────────────────┘
移动：按上述阅读顺序单列排列，导航允许换行。
```

Signature 是真实内容组成的工作台：蓝色侧边签、按已有主题组织的可读标题，以及项目章节入口。自评后删除了无意义的序号、统计和虚构“正在进行”状态；边框、留白和字体承担结构。

## 实现与内容规则

`index.vue` 消费 `useSiteInventory()` 返回的普通数组 `entries`、`articles`、`projectChapters` 及 `legacyContentUrl`。不修改数组，排除草稿，精选使用 `featured`，近期按有效 `lastmod` / `date` 排序。没有日期时不伪造日期。没有可读内容时显示清楚的空态；工作台不展示空主题。项目介绍取真实项目索引，找不到索引时取已有项目章节，均不存在时隐藏项目展示。

站内页面使用 NuxtLink：`/articles/`、`/topics/`、`/projects/`、`/about/`。旧内容统一经 `legacyContentUrl(entry.path)` 生成链接，便于主代理替换配置。SEO 描述面向读者，不展示实现技术或迁移状态。

## 共享样式契约

- `.site-container`：最大宽度 1180px，移动侧边距 20px。
- `.site-header`：白色底与下边线；内部或同元素 `.site-container` 为 flex，品牌与导航可换行。
- `.site-brand`：站点品牌链接；可包含 `.site-brand-mark`、`.site-brand-name`、`.site-brand-note`。
- `.site-nav`：flex 导航，当前链接支持 `[aria-current="page"]`、`.router-link-exact-active` 和 `.is-active`。
- `.site-footer`：上边线与辅助文字；内部容器支持文字和链接组。
- `.skip-link`：聚焦可见跳转链接；shell 的 main 提供 `#main-content` 与 `.site-container`，首页不重复容器宽度或 ID。
- 首页类使用 `home-` 前缀；共享 token 使用 `--site-*`。

共享索引页样式已按实际 `articles.vue`、`topics.vue`、`projects.vue`、`about.vue` 结构补齐：`.page-section` / `.eyebrow` / `.page-intro`，文章筛选与结果列表、专题与项目面板、章节列表和 `.prose` 正文。索引页大标题只选择 `.page-section > h1`，正文标题只选择 `.prose` 后代，首页保留自己的排版。筛选保留原生 radio、44px 标签点击区、选中与键盘聚焦反馈；专题双列在移动屏变为单列，正文代码与表格横向滚动。接续了主代理同步添加的页面基础样式，以增量方式补齐缺失的契约和正文排版。

适配 320px 起的单列屏幕；链接有键盘 focus；内容不依赖 hover；不使用持续动画，reduced-motion 关闭滚动和过渡。首页不额外创建 main landmark，使用 article 容器，供 shell 的 main 包裹。

## 验证与边界

使用实际 inventory 执行首页数据筛选：获得 2 篇精选、Agent / RAG 各 2 个工作台入口、4 条近期更新和 8 个项目章节；近期列表不含草稿。检查 CSS 花括号配对及无远程字体导入。对接 shell 后取消了首页重复的容器宽度与 main ID，并兼容 shell 的 `.is-active` 导航类。精选网格自适应实际文章数，不为缺少的第三篇占空列。

首页与样式由本任务提供；Nuxt 配置、shell、内容数组由主代理提供。最终预览需在这些接口接入后确认桌面/移动布局、键盘导航和真实链接。本文件不宣称未执行的浏览器验证。
