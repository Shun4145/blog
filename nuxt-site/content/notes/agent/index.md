欢迎来到「Agent 技术笔记」—— 这里不是泛泛而谈的应用层教程，而是一份致力于拆解智能体（Agent）底层逻辑的工程实录。本模块聚焦于 Agent 的核心三角色：规划（Planning）、工具调用（Tool Use） 与 反思机制（Reflection），深入探讨 Chain-of-Thought 的工程化落地、记忆模块的向量化存储方案，以及 Multi-Agent 协作中的通信开销与共识算法。笔记内容均源于实际项目的踩坑总结与性能调优，适合不满足于调包、渴望理解 Agent “大脑”如何运转的开发者。
